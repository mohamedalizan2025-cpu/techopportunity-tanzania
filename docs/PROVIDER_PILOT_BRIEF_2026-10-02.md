# Provider-pilot brief — AFTER user validation only (2026-10-02)

Do not run this before the user pilot in
[USER_VALIDATION_PILOT_2026-10-02.md](USER_VALIDATION_PILOT_2026-10-02.md)
passes its success criteria. One provider, one opportunity, one community,
two weeks, free discovery run. No customers, revenue, pricing acceptance, or
traction is claimed here — the pilot exists to discover whether any exists.

## Offer (staff-managed service, no payment infra)

Tech Opportunity verifies and classifies one legitimate provider opportunity,
distributes it to one reachable consenting campus/developer community, and
returns a manual aggregate report. Charge is for staff work and delivery, never
for passing verification. No guaranteed applicant counts. No automated
targeted sending and no conversion attribution is claimed — the current pilot
counts overlapping Saved/Interested/Applying/Applied states, not a causal
funnel.

## Flow

Verified opportunity → agreed community distribution → aggregate
Saved/Interested/Applying/Applied report (counts only — no names, emails,
profile rows, or per-user lists, ever; small-cell suppression reviewed before
any external report). Paid distribution, if ever agreed later, is labeled
Sponsored and never changes verification, eligibility rules, or Explore
completeness. Private talent data is never sold; introductions require
specific consent and remain unbuilt.

## Provider prerequisites (all required before the run)

One reachable consenting community; one timely, independently reviewed open
call; a provider-approved delivery brief stating their existing distribution
baseline; agreed count definitions; measured staff effort/cost log; and a
named buyer willing to pay for the NEXT run. Document actual agreement.

## Report contents (manual, aggregate only)

Reach as actually measured; return visits; source visits where obtainable
without new tracking; self-reported application progress; provider feedback;
staff hours. End with a real scoped price proposal for a repeat run and a
recorded renewal decision — yes or no, with reason. No invented acceptance.
